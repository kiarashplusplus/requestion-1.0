# Distribution: Google Search/News, local outlets, AI assistants (research as of 2026-10-05)

## Google
- **No Publisher Center submission.** "Google automatically considers all web content for inclusion in Google News." Since March 2025 Google News no longer uses submitted RSS feeds; manual applications closed Oct 2025. Content policies require clear dates and bylines, publisher/company information and contact details.
- **Sitemaps:** `/sitemap.xml` index → `/sitemaps/posts-YYYY-MM.xml`, `/sitemaps/hubs.xml`; `<lastmod>` = last real data change; 50k URLs / 50 MB per file. **News sitemap** `/news-sitemap.xml`: only posts from the last two days, ≤ 1,000 `<news:news>` entries, `<news:publication><news:name>request.news</news:name><news:language>en</news:language></news:publication>`, `<news:publication_date>` W3C with offset, `<news:title>`. Submit in Search Console. Ping endpoint is gone (June 2023). **Google does not use IndexNow.** Indexing API is only for JobPosting/BroadcastEvent.
- **Structured data per post** (JSON-LD `@graph`): `NewsArticle` { headline, image [16:9 ≥ 1200 px, 4:3, 1:1; ≥ 50k px], datePublished, dateModified (with offset; only on real change), author (Organization "request.news" with url), publisher (Organization with logo), dateline ("HOUSTON, Texas"), isBasedOn/citation (source feed URLs), mainEntityOfPage } + `Dataset` { name, description 50–5000 chars, license CC BY 4.0 URL, creator, temporalCoverage (ISO week), spatialCoverage (Place with geo), distribution [DataDownload CSV + JSON] } + `BreadcrumbList` (us › tx › houston). Visible "Published" / "Updated" with timezone matching the markup. `<meta name="robots" content="max-image-preview:large">`. No `LocalBusiness`. Speakable: skip.
- **Spam policies (updated 2026-08-28):** scaled content abuse ("generative AI tools … to generate many pages without adding value", "scraping feeds … to generate many pages", "stitching or combining content"), doorway abuse ("substantially similar pages … closer to search results than a clearly defined, browseable hierarchy"). AI content guidance (2026-10-01): "critical to manually factcheck and review all AI-generated content"; disclose how content was created. Our defenses: demand-gated creation, one canonical slug per (place, fuel, ISO week), minimum-data gate else `X-Robots-Tag: noindex` and exclusion from sitemaps/feeds/IndexNow, browsable hubs, truthful `dateModified`, programmatic fact-check of the digest, disclosure, `/methodology`, `/editorial-policy`, `/corrections`.
- **Technical:** SSR HTML (crawlers may wait in the render queue); self-referencing absolute canonical; strong `ETag` + `Last-Modified`, answer 304; `Cache-Control: public, max-age=300, s-maxage=3600, stale-while-revalidate=86400`; Core Web Vitals LCP < 2.5 s, INP < 200 ms, CLS < 0.1. Add the **Google Preferred Source** button (global since Dec 2025; ~2× clicks for subscribers). Search Console "Search Generative AI performance" report exists (June 2026).
- **Local:** Google documents no way to declare a coverage area. Signals: city in headline, visible dateline, `NewsArticle.dateline`, `spatialCoverage`/`contentLocation`, city hub pages.

## Local outlets and syndication
- Feeds: `/feed/<region>.xml` (RSS 2.0, full text in `content:encoded`, `media:content` → card PNG), `/feed/<region>.json` (JSON Feed 1.1: `version`, `title`, `items[{id, content_html}]`, `application/feed+json`, discovery `<link rel="alternate" type="application/feed+json">`), `/feed/all.xml`. Google Feedfetcher fetches RSS/Atom for WebSub.
- oEmbed 1.0: discovery `<link rel="alternate" type="application/json+oembed" href="/oembed?url=…">`; `rich` response `{type, version:"1.0", html (iframe of /embed/<slug>), width, height}`. Embed attribution must be a plain brand link (Google forbids keyword-rich widget links).
- `/data/<slug>.csv|json` as `Dataset.distribution`; license CC BY 4.0 with attribution "Source: request.news (request.news), data from EIA/BLS"; only `Feed.license.redistributable` rows are included.
- Dateline style: "HOUSTON, Texas (request.news) —". Weekly `/press` state releases modeled on GasBuddy's templated releases.

## AI assistants
- **Crawlers to allow:** OAI-SearchBot (ChatGPT search; opting out removes you from answers), ChatGPT-User, Claude-SearchBot, Claude-User, PerplexityBot (search only), Perplexity-User, Googlebot (Search, AI Overviews, AI Mode), **Google-Extended** (controls Gemini training **and grounding**; blocking removes Gemini app citations; no effect on Search), Bingbot (Copilot), Applebot. Training-only (owner's choice, disallowed by default): GPTBot, ClaudeBot, Applebot-Extended.
- **robots.txt** is served by the Worker (`apps/api/src/routes/agent.ts`) with `Content-Signal: search=yes, ai-input=yes, ai-train=no` (Cloudflare Content Signals Policy, Sept 2025: `search` = indexing/links, `ai-input` = RAG/grounding, `ai-train` = training).
- **Cloudflare zone settings:** turn **managed robots.txt OFF** (it prepends disallows for ClaudeBot/GPTBot etc.). In Security › "Configure AI bot policies" (defaults effective 2026-09-15): Search = Allow, Agent = Allow; **never set Training = Block at the category level** ("multi-purpose crawlers such as Googlebot, Applebot, and BingBot will be blocked by customers who have selected to block Training"); block training-only crawlers individually in AI Crawl Control, or use "Disallow AI Training" for accountable mixed-use crawlers. Check Bot Fight Mode/WAF don't challenge verified bots. Crawler Hints on, but also POST IndexNow (`api.indexnow.org/indexnow`, key file at `/.well-known/indexnow/<key>.txt`) from `PostsWorkflow` for Bing/Copilot/ChatGPT search.
- **llms.txt:** Google says it neither helps nor harms; OpenAI/Anthropic/Perplexity support UNVERIFIED. Ship a cheap curated index at `/llms.txt`.
- **MCP** (spec 2026-07-28: stateless, no `initialize`/`Mcp-Session-Id`, `server/discover`, `subscriptions/listen`, `ttlMs` + `cacheScope` on list results, `Mcp-Method`/`Mcp-Name` headers; HTTP+SSE deprecated): Cloudflare `createMcpHandler` from `agents/mcp/server` with MCP SDK v2 (`McpServer.registerTool` + zod), authless, default route `/mcp`, `corsOptions`; `McpAgent` is legacy. Confirm the installed handler's spec version. Tools: `get_latest{country, region?, fuel?, unit?}`, `get_history{region, fuel, range}`, `search_regions{q, country?}`, `get_post{slug}`, `list_posts{country?, limit}`, `get_macro{country}`; each with `title`, `readOnlyHint: true`, ≤ 64-char names; every result includes `source[]`, `as_of`, `canonical_url`, `license`; `ttlMs: 300000`, `cacheScope: "public"`. Rate-limit with the `ratelimits` binding.
- **Listings:** Official MCP Registry (preview) as `news.request/gas-prices` via `/.well-known/mcp-registry-auth` (`v=MCPv1; k=ed25519; p=<pubkey>`) + `server.json` with `remotes:[{type:"streamable-http", url:"https://request.news/mcp"}]`; Claude Connectors directory (tools need `title` + `readOnlyHint`, actionable errors, domain matches service); ChatGPT: Developer mode connector now, plugin directory submission (`/.well-known/openai-apps-challenge`, 5 positive/3 negative test cases, video, verified org); Perplexity custom connectors by URL; Gemini CLI `mcpServers.httpUrl`, Gemini API `mcp_server` tool (lowercase alphanumeric server name). Custom GPT Actions are being retired (Dec 2026); OpenAPI at `/openapi.json` is for developers/Gemini only.
- **Freshness:** ChatGPT search uses third-party search (Bing) + OAI-SearchBot; Bing Webmaster Tools "AI Performance" shows Copilot citations; IndexNow helps Bing-side freshness; Gemini/AI Overviews use the Google index (sitemaps + news sitemap). AI referrals carry `utm_source=chatgpt.com` etc.

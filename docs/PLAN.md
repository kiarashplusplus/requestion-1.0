# request.news: US gas prices as the local news, built on the 2026 Cloudflare stack

## Context

The owner is rebuilding their 2019 "Requestion" sticker app from the ground up as **request.news**: a **US-only**, data-first local-news product where a user **requests a place** and the system auto-publishes a verified, continuously refreshed post about **gas prices with inflation context and an AI re-digest of local fuel news**, discoverable by Google Search/News, local outlets and AI assistants (ChatGPT, Gemini, Claude, Perplexity), amplified by TikTok/Instagram cards and Google + TikTok ads from launch. Everything runs on Cloudflare. Nothing from the old repos is imported as code or history; only brand tokens, fonts, icon/splash, app identity and a few patterns carry over.

**This session's deliverable:** an implementation brief for an agent swarm, committed to a new private repo `kiarashplusplus/request.news` on branch `claude/gas-prices-app-rebuild-4ww0r7`, with a PR. Draft at `scratchpad/REBUILD_BRIEF.md`.

## Architecture: 2026 Cloudflare base stack (verified 2026-10-05)

- **Toolchain:** wrangler 4.147 + `wrangler.jsonc` (`compatibility_date` 2026-10-05; nodejs_compat default), Workers Paid, TypeScript 7, pnpm + Turborepo 2.11, Hono 4.13 + `@hono/zod-openapi` + zod 4, Drizzle 0.45 (D1), `@cloudflare/vitest-plugin` 1.3.6 + vitest 4.x (not 5), `@cloudflare/workers-types`. **Do not adopt the beta `cf` CLI.**
- **Runtime shape:** `apps/api` Worker (Hono API, SSR posts/hubs, cards, MCP, 4 Workflows) + `apps/web` assets-only Worker (`cache` off). **Workflows with cron `schedules`** for ingestion (not Cron handler + Queues). R2 raw payloads → D1 history → KV latest snapshots. **Workers Cache** (`cache.enabled`) honoring `Cache-Control` + `Cache-Tag`, purged via `ctx.cache.purge`. Analytics Engine (feed freshness, hits by country), `ratelimits` binding, Workers AI (`gpt-oss-120b` write / `gpt-oss-20b` extract) via AI Gateway. **satori 0.35 + resvg-wasm** in-Worker for cards (not Browser Run); JPEG/WebP encode step for IG/TikTok APIs. Workers Builds + Worker Previews deploy; GitHub Actions checks only. Secrets via `wrangler secret put`; `.dev.vars` local.
- **D1 tables:** `feed`, `region`, `price_observation` (+grade, min/max, n_stations), `station_latest`, `daily_rollup`, `fx_rate`, `macro_series`, `macro_observation`, `news_source`, `news_item`, `digest`, `feed_run`, `request`, `post`. Prune observations > 400 d.
- **KV keys:** `latest:v1:global|country:{CC}|country:{CC}:region:{R}`, `meta:v1:feeds`, `macro:v1:country:{CC}`, `fx:v1:latest`, `posts:v1:index`, `digest:budget:{date}`. One write per key per run.
- **Edge geo + US gate:** HTML routes check `request.cf.country === 'US'` (plus a Cloudflare WAF country rule as belt-and-braces); non-US visitors get a static "request.news is available in the United States" page with `noindex`, no pixels, no cookies. Default region from `cf.regionCode`/`cf.city` for pre-selection only; never persist IP/lat-long/city. `/v1/*`, `/mcp`, feeds, sitemaps and cards stay world-readable (no personal data, no cookies) so crawlers and AI agents outside the US still index/cite.
- **US privacy baseline:** no consent banner; privacy policy + "Your Privacy Choices" footer link; detect `Sec-GPC: 1` and suppress ad pixels/sharing for that visitor; Google Ads Restricted Data Processing and TikTok Limited Data Use flags for opted-out visitors; pixels loaded via Cloudflare Zaraz (or server-side Events APIs from Workers) so the gate is enforced in one place. CCPA/CPRA thresholds likely not met at launch; implement the opt-out anyway (cheap, and ads "sharing" counts toward the threshold).
- **Posts gate:** publish iff ≥ 5 observations in 7 d, latest ≤ 72 h, one post per (region, fuel, ISO week) else `request_count++`; thin → `status=noindex` + `X-Robots-Tag: noindex`, excluded from sitemaps/feeds/IndexNow. `dateModified` only on real data change.

## Data feeds

- **Fuel at launch (US-only):** `us-eia-weekly` only (EIA v2 `https://api.eia.gov/v2/{route}/data?api_key=…&frequency=weekly&data[]=value&facets[…]`, free key, `length` ≤ 5000, public domain; weekly national, PADD, state and 10-metro regular/midgrade/premium/diesel). WS-B records exact route/facets/series in `docs/feeds.md` first. **Phase 2 adapters (designed into the registry, not shipped):** `eu-oil-bulletin`, `de-tankerkoenig`, `fr-prix-carburants`, `gb-cma-fuel-finder`, `au-nsw-fuelcheck`, `au-wa-fuelwatch`, `ca-nrcan-weekly`. No FX needed at launch (USD only); FX adapter deferred. Never scrape commercial aggregators (GasBuddy/OPIS/AAA).
- **Macro (CPI) at launch:** BLS v2 only (free key, 500 q/day, 50 series/query; `CUUR0000SA0/SA0E/SETB/SETB01` national, 4 regions `CUUR0100/0200/0300/0400…`, 23 metros e.g. `CUURS12ASETB01` NY, `CUURS49ASETB01` LA, `CUURS37BSETB01` Houston; Oct-2025 CPI missing due to shutdown; required attribution statement; metro cadence partly bimonthly, UNVERIFIED). FRED only as mirror. Real = nominal × CPI_base/CPI_t (all-items NSA, same geography); keep "fuel CPI vs headline" separate from "deflated pump price"; label lags. Phase 2: Eurostat `prc_hicp_minr`, ONS, StatCan, ABS, World Bank, IMF (details retained in the brief appendix).
- **News for re-digest (US sources):** GDELT DOC 2.0 with `sourcecountry:US` (free commercial w/ citation; 1 req/5 s per IP → serialize + KV cache; themes `FUELPRICES`, `ECON_GASOLINEPRICE`, `ECON_OILPRICE`), **GNews Essential €49.99/mo** (commercial, real-time, `country=us`), Mediastack backup, EIA Gasoline & Diesel Update RSS + Today in Energy (public domain), curated US local-outlet RSS registry. **Not** Google News RSS (non-commercial only), NewsAPI.org dev tier, Bing (retired). EU press-publisher right not applicable while US-only; US fair-use posture still metadata-only. Digest = headline + outlet + date + canonical link + 1–2 own-words sentences; no verbatim, no third-party thumbnails; respect `Content-Signal: ai-input=no`. Pipeline: discover → canonical-URL + SimHash dedupe → place+fuel filter + 20b classifier → 20b claim extraction (JSON schema) → 120b digest with `[n]` citations → numeric check vs D1 (±0.5 last digit) or cited claim → retry once, else digest without numbers → disclosure + required attributions. `DIGEST_DAILY_BUDGET` ≈ 300/day (≈ $1/day).

## Notifications: US-only legal envelope

With US-only scope the rules collapse to: **CAN-SPAM** for email (unsolicited email permitted if headers are truthful, sender identified with a physical postal address, a working opt-out honored within 10 business days, no harvested/dictionary addresses; recurring mail to addresses users typed into the request form is lawful), **TCPA** for SMS/WhatsApp to US numbers (prior express consent for automated messages), and **Meta's WhatsApp Business policy** (documented opt-in required regardless of law). Design: the request form captures an email with a clear-purpose line ("we'll email you when your page is live and send weekly price updates; unsubscribe anytime"); transactional "request received / page is live" immediately; weekly digest + ≥10¢ price alerts to the same address under CAN-SPAM with `List-Unsubscribe` + one-click (RFC 8058), suppression list in D1, Gmail/Yahoo bulk-sender requirements (SPF+DKIM+DMARC, <0.3 % spam rate). WhatsApp: a public Channel + `wa.me` opt-in capture at launch; Cloud API utility templates only after opt-in. Sending provider: Cloudflare Email Sending if GA with sufficient volume, else Resend/SES from Workers (WS-N confirms status, limits and prices against primary sources, since the dedicated researcher was stopped before reporting).

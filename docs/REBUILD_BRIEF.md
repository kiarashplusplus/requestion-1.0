# request.news: implementation brief

**Audience:** the agents implementing this repo (see `SWARM_PLAN.md` for who does what). Read this file, `contracts.md` and your workstream's row in `SWARM_PLAN.md` before writing code.
**Facts:** platform versions, limits and policies were checked against npm, developers.cloudflare.com and platform policy pages on 2026-10-05. Items marked UNVERIFIED must be confirmed before relying on them.

## 1. Product

request.news is a **US-only, data-first local-news product**: a user **requests a place** (state, metro, city) and the system auto-publishes a verified, continuously refreshed post about **gas prices there**, with **inflation context** (CPI, gasoline CPI) and a **fact-checked AI re-digest of the week's local fuel news**. Posts are built to be discovered and cited by Google Search/News, local outlets (feeds, embeds) and AI assistants (crawl + a read-only MCP server), amplified by share cards on TikTok and Instagram and by Google and TikTok ads from launch.

Owner decisions (2026-10-05): consumers first; US-only (EIA + BLS data at launch; other countries' adapters designed but not shipped); web-first, Expo app in phase 2; fuel + inflation only in year one; one post per request/place/week, no free-text UGC; no monetization in year one; brand and domain `request.news`; operator "Kiarash Adl, an individual in Texas doing business as request.news" (Terms/Privacy ported from keepsake.ing); email notifications under CAN-SPAM, WhatsApp via Channels; TikTok + Instagram as social channels (Snapchat dropped); Google Ads + TikTok Ads from launch.

Prerequisites only the owner can do: register `request.news` on Cloudflare Registrar (it is unregistered as of 2026-10-05; `requestion.app` has lapsed too), create the private GitHub repo and connect Workers Builds, get a PO Box/CMRA address for CAN-SPAM, obtain EIA and BLS API keys, create Meta (Facebook App ID, Instagram professional account) and TikTok Business accounts, start Google Ads advertiser verification on day 1.

- **Deploy:** Workers Builds (git-connected, one build config per Worker, deploy command `wrangler d1 migrations apply DB --remote && wrangler deploy` for the API) + Worker Previews per PR; GitHub Actions runs checks only (`.github/workflows/ci.yml`). ## 3. Data

- **Fuel (launch):** `us-eia-weekly` only. EIA Open Data API v2, base `https://api.eia.gov/v2/`, `api_key` query param (free key at eia.gov/opendata), route `/petroleum/pri/gnd/data` with `frequency=weekly`, `data[]=value`, `facets[...]`, `length` ≤ 5000; weekly national, PADD 1–5, nine states (CA, CO, FL, MA, MN, NY, OH, TX, WA) and ten metros (Boston, Chicago, Cleveland, Denver, Houston, Los Angeles, Miami, New York, San Francisco, Seattle) for regular/midgrade/premium gasoline and diesel; public domain; attribution "Source: U.S. Energy Information Administration". WS-B verifies facet names and series ids and records them in `feeds.md`. No open US station-level feed exists (GasBuddy/OPIS/AAA are proprietary and must not be scraped). Phase 2: EU Weekly Oil Bulletin, Tankerkönig, data.gouv.fr, UK CMA, NSW FuelCheck, WA FuelWatch, NRCan.
- **Macro (launch):** BLS Public Data API v2 (free key, 500 queries/day, 50 series/query, renew yearly; `POST https://api.bls.gov/publicAPI/v2/timeseries/data/`). Series `CUUR0000SA0` (all items), `CUUR0000SA0E` (energy), `CUUR0000SETB` (motor fuel), `CUUR0000SETB01` (gasoline); 4 regions; 23 metros (e.g. `CUURS12ASETB01` NY, `CUURS49ASETB01` LA, `CUURS37BSETB01` Houston; cadence partly bimonthly, UNVERIFIED). October 2025 CPI does not exist (shutdown). Required statement: "BLS.gov cannot vouch for the data or analyses derived from these data after retrieval." Real = nominal × CPI_base / CPI_t using the all-items NSA index for the same geography; keep "gasoline CPI vs headline CPI" (relative price) separate from "deflated pump price" (real level); label lags. FRED only as a mirror. DBnomics is stale; don't use.
- **News for the re-digest (US):** GDELT DOC 2.0 (`https://api.gdeltproject.org/api/v2/doc/doc?query=(theme:FUELPRICES OR theme:ECON_GASOLINEPRICE) sourcecountry:US&mode=artlist&maxrecords=250&timespan=7d&format=json`; free for commercial use with citation; **1 request per 5 s per IP**, so serialize and cache in KV 15 min; no snippets; noisy), GNews Essential (€49.99/mo, explicit commercial use, real-time, `country=us`), EIA Gasoline & Diesel Update RSS (`https://www.eia.gov/petroleum/gasdiesel/includes/gas_diesel_rss.xml`) and Today in Energy RSS (public domain), curated US local-outlet RSS registry. **Do not use** Google News RSS (its own copyright notice limits it to personal, non-commercial feed readers), NewsAPI.org dev tier (no production), Bing News (retired 2025-08-11).
- **Digest pipeline:** discover → canonical-URL normalization + 64-bit SimHash (Hamming ≤ 3) → place + fuel-term filter + 20b classifier → 20b claim extraction with JSON schema (value, unit, period, geography, article URL, evidence span ≤ 25 words) → 120b digest at low/medium reasoning with `[n]` citations → numeric check (every number matches a D1/macro value within ±0.5 last digit for the same period and geography, or a cited claim labeled "reported by X") → one regenerate, else digest without numbers → disclosure "AI-generated summary; sources linked; data: EIA, BLS". Metadata only (title, outlet, date, canonical link, ≤ 300-char `og:description`), no verbatim beyond a short phrase, no third-party thumbnails, honest UA `RequestNewsBot/1.0 (+https://request.news/about)`, respect `Content-Signal: ai-input=no`. Budget `DIGEST_DAILY_BUDGET` 300/day (≈ $1/day on 120b).

## 4. Posts

Demand-gated, data-driven SSR pages at `/p/<slug>` (`houston-tx-gas-prices-2026-w41`) within a browsable hub hierarchy `/us`, `/us/tx`, `/us/tx/houston`. Each post shows: H1 with the place, visible byline (`request.news`), dateline ("HOUSTON, Texas"), published and updated times with timezone, latest price + unit, change vs 7 d and 30 d, comparison to the national average, 7-day sparkline, CPI context sentence with sources, optional accepted digest with disclosure and per-claim links, source list with license and "as of", "cite this" box, share buttons, request-your-city CTA, "nearby places requested" module. JSON-LD `@graph`: `NewsArticle` (headline ≤ 110, `dateline`, `isBasedOn`, images 16:9 ≥ 1200 px + 4:3 + 1:1, dates with offset, `author`/`publisher` Organization with url + logo) + `Dataset` (name, description, `license` CC BY 4.0, `distribution` CSV/JSON, `temporalCoverage`, `spatialCoverage`) + `BreadcrumbList`; `max-image-preview:large`; OG/Twitter tags to the 1200×630 card; self-referencing canonical; strong ETag + 304s.

Gate: ≥ 5 observations in 7 days, latest ≤ 72 h old, one post per (region, fuel, ISO week) else `request_count++`; thin posts are `noindex` and excluded from sitemaps, feeds, IndexNow and the posts index. `dateModified` changes only when `dataHash` changes. Google's scaled-content and doorway policies are the reason for every one of these rules.

## 5. Distribution

- **Google:** inclusion in News/Top Stories is algorithmic (no Publisher Center application; closed Oct 2025). Ship `/sitemap.xml` index (+ `/sitemaps/posts-YYYY-MM.xml`, `/sitemaps/hubs.xml`) and `/news-sitemap.xml` (posts from the last 48 h, ≤ 1,000, `news:name` exactly "request.news"). Submit in Search Console; add the Preferred Source button. Ping is gone; Google ignores IndexNow; Indexing API not applicable.
- **Local outlets:** `/feed/<region>.xml` (full text, `media:content` → card), `/feed/<region>.json` (JSON Feed 1.1), `/oembed?url=` → iframe `/embed/<slug>` with a plain brand link (no keyword anchors), `/data/<slug>.csv|json`, `/press` weekly state releases, `/methodology`, `/corrections`. Growth loop #1 is this citation loop (see `growth.md`).
- **AI assistants:** Worker-served `/robots.txt` with `Content-Signal: search=yes, ai-input=yes, ai-train=no`; allow OAI-SearchBot, ChatGPT-User, Claude-SearchBot, Claude-User, PerplexityBot, Perplexity-User, Googlebot, **Google-Extended** (blocking it removes Gemini grounding), Bingbot, Applebot; disallow training-only GPTBot, ClaudeBot, Applebot-Extended. Cloudflare zone: managed robots.txt OFF; in "Configure AI bot policies" never set Training=Block at category level (that also blocks Googlebot/Bingbot/Applebot); allow citation bots individually in AI Crawl Control; Crawler Hints on, but also POST IndexNow from `PostsWorkflow` (Bing/Copilot/ChatGPT search). `/llms.txt` optional.
- **MCP:** spec 2026-07-28 (stateless, `server/discover`, `ttlMs`/`cacheScope`); Cloudflare `createMcpHandler` from `agents/mcp/server` with MCP SDK v2 (`McpAgent` is legacy); authless, read-only tools `get_latest`, `get_history`, `search_regions`, `get_post`, `list_posts`, `get_macro`, each with `title` and `readOnlyHint: true`, results carrying `source`, `as_of`, `canonical_url`, `license`. Register `news.request/gas-prices` in the MCP Registry (`/.well-known/mcp-registry-auth`), the Claude Connectors directory, and the ChatGPT plugin directory (`/.well-known/openai-apps-challenge`); custom GPT Actions are being retired.
